# Linux Server Automation

A practical collection of tools and playbooks for Linux server administration, configuration, and health checks.

## Components

- **Bash:** Automation scripts for server setup, routine administration, and health checks.
- **Ansible:** Playbooks for configuration management and security-state verification.
